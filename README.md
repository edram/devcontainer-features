# Dev Container Features

A collection of [Dev Container Features](https://containers.dev/implementors/features/).

## Features

| Feature | Description |
| ------- | ----------- |
| [`claude-code`](./src/claude-code) | Installs the [Claude Code](https://code.claude.com/docs) CLI globally on the PATH. |

## Usage

Reference a feature in your `devcontainer.json`:

```jsonc
{
    "image": "mcr.microsoft.com/devcontainers/base:ubuntu",
    "features": {
        "ghcr.io/edram/devcontainer-features/claude-code:1": {
            "version": "stable"
        }
    }
}
```

## Publishing

Features are published to the GitHub Container Registry (GHCR) automatically by
the [`release.yaml`](./.github/workflows/release.yaml) workflow on every push to
`main`. To enable publishing:

1. Repository **Settings → Actions → General → Workflow permissions**: select
   **Read and write permissions**.
2. Push to `main` (or run the workflow manually via **Actions → Release →
   Run workflow**).
3. After the first successful run, find the published package under the
   repository's **Packages** and set its visibility to **Public** so others can
   consume it.

The published image reference is
`ghcr.io/<owner>/devcontainer-features/<feature-id>`.

## Documentation

A `README.md` for each feature is generated automatically from its
`devcontainer-feature.json` by the
[`update-documentation.yml`](./.github/workflows/update-documentation.yml)
workflow, which opens a pull request with the updated docs on every push to
`main`.

That PR is created with a personal access token so it can in turn trigger CI.
Add a repository secret named **`PAT`** (a fine-grained or classic PAT with
`contents: write` and `pull-requests: write` on this repo). Without it, the
documentation PR step will fail to authenticate.

## Testing

Pull requests and pushes run [`test.yaml`](./.github/workflows/test.yaml), which
uses the `devcontainer` CLI to run both the autogenerated `test.sh` checks and
the [`scenarios.json`](./test/claude-code/scenarios.json) scenarios.

Run the tests locally:

```bash
npm install -g @devcontainers/cli
devcontainer features test --features claude-code --base-image mcr.microsoft.com/devcontainers/base:ubuntu .
```
